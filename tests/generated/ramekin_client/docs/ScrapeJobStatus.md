# ScrapeJobStatus

A scrape job's status. `completed` and `failed` are terminal; while an import or scrape is `normalizing` its recipe is already saved.

## Enum

* `PENDING` (value: `'pending'`)

* `SCRAPING` (value: `'scraping'`)

* `PARSING` (value: `'parsing'`)

* `NORMALIZING` (value: `'normalizing'`)

* `COMPLETED` (value: `'completed'`)

* `FAILED` (value: `'failed'`)
