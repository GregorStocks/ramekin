# Add Density for a High-Priority Ingredient

Pick one high-impact ingredient from the density gap report, find a reliable density, and add it.

## Workflow

1. **Read the gap report** (`data/density-gap-report.txt`) and identify the top ~20 entries
2. **Skip** ingredients with a deliberate `{"none": reason}` density or a `null` (ambiguous) alias in `curated.json` (black pepper variants, sea salt, fine salt, cheese, etc.)
3. **Pick one** high-occurrence ingredient (or family of related variants) that can be resolved, and **ask the user to confirm your choice before proceeding**
4. **Research the density:**
   - Best: USDA FoodData Central (`fdc.nal.usda.gov`) with FDC ID and URL
   - Good: reputable cooking reference (King Arthur, Serious Eats) with URL
   - OK: estimation with documented rationale (e.g. "comparable to X which is Y g/cup")
   - Check if the ingredient is already in `usda.json` (`names` or a food `description`) under a different name (just needs an alias)
5. **Edit `ramekin-core/src/catalog/data/curated.json`** (format in `ramekin-core/src/catalog/README.md`):
   - If it's a new density: add to `"entries"` with `grams_per_cup: {value, source, url}`, plus `fdc_id` when USDA has the food (so calories work too)
   - If it's an alias to existing data: add to `"aliases"` (aliases may not shadow an existing name)
   - Add all common spelling variants you see in the gap report
6. **Add tests** in `ramekin-core/tests/catalog_tests.rs` in the appropriate test function
7. **Update golden files:** `make ingredient-tests-update`
8. **Verify:** `make test` and `make lint`
9. **Regenerate the gap report and audit:** `make pipeline` (also refreshes `data/ingredient-catalog-audit.md`)
10. **Commit and create a PR**

## Key files

- `ramekin-core/src/catalog/data/curated.json` -- hand-curated entries, aliases, and rewrites (overrides USDA)
- `ramekin-core/src/catalog/data/usda.json` -- USDA FoodData Central foods and densities (generated by `make catalog-import`)
- `ramekin-core/src/catalog/resolve.rs` -- lookup logic, modifier stripping
- `ramekin-core/tests/catalog_tests.rs` -- tests
- `data/density-gap-report.txt` -- ingredients missing density data, sorted by frequency

## Density format

All densities are **grams per US cup** (236.588 ml). To convert:
- From g/tbsp: multiply by 16
- From g/tsp: multiply by 48

## Important

- Never guess. If you can't find a reliable source, give the entry `{"none": reason}` for its density (or a `null` alias if the name itself is ambiguous) rather than estimating poorly.
- One ingredient family per PR.
- Stop after creating the PR.
