# Scrape Status Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the single-string scrape status in the UI with a dedicated `/scrape/:id` page that shows live per-step status, short summaries, and raw per-step outputs on demand so broken scrapes are debuggable from the browser.

**Architecture:** Extend `GET /api/scrape/{id}` with a derived `steps` array and add `GET /api/scrape/{id}/steps/{step_name}/output`. Add a `current_step_started_at` column on `scrape_jobs` so the running step has a real start time. Build a new React page that polls the extended endpoint and lazy-loads per-step output on expand. Redirect the two existing submit flows (`/recipes/new`, `/capture`) to the new page.

**Tech Stack:** Rust (Axum, Diesel, utoipa), Postgres (Diesel migrations), TypeScript/React (Vite), generated OpenAPI clients, Python pytest for end-to-end tests.

pub const PIPELINE_STEPS: &[&str] = &[
    "fetch_html",
    "extract_recipe",
    "fetch_images",
    "parse_ingredients",
    "save_recipe",
    "enrich_normalize_ingredients",

#[derive(Debug, Clone, Serialize, ToSchema)]
pub struct StepState {
    pub name: String,
    pub status: String, // "pending" | "running" | "completed" | "failed" | "skipped"
    #[serde(skip_serializing_if = "Option::is_none")]
    pub started_at: Option<DateTime<Utc>>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub finished_at: Option<DateTime<Utc>>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub duration_ms: Option<i64>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub summary: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub error: Option<String>,
    pub has_output: bool,
}

/// Produce a short human-readable summary line for a completed step.
/// Returns None when the step's output has no interesting fields to surface.
pub fn step_summary(step_name: &str, output: &JsonValue) -> Option<String> {
    match step_name {
        "fetch_html" => {
            let bytes = output.get("html_byte_len").and_then(|v| v.as_i64())?;
            Some(format!("{} bytes fetched", bytes))
        }
        "extract_recipe" => {
            let title = output.get("recipe").and_then(|r| r.get("title")).and_then(|t| t.as_str())?;
            Some(format!("extracted \"{}\"", title))
        }
        "fetch_images" => {
            let succeeded = output.get("succeeded").and_then(|v| v.as_i64()).unwrap_or(0);
            let requested = output.get("requested").and_then(|v| v.as_i64()).unwrap_or(0);
            Some(format!("{}/{} images", succeeded, requested))
        }
        "parse_ingredients" => {
            let count = output.get("ingredients").and_then(|v| v.as_array()).map(|a| a.len())?;
            Some(format!("{} ingredients parsed", count))
        }
        "save_recipe" => {
            let id = output.get("recipe_id").and_then(|v| v.as_str())?;
            Some(format!("saved recipe {}", id))
        }
        "enrich_auto_tag" => {
            let count = output.get("tags").and_then(|v| v.as_array()).map(|a| a.len())?;
            Some(format!("{} tags suggested", count))
        }
        "apply_auto_tags" => {
            let applied = output.get("applied").and_then(|v| v.as_i64())?;
            Some(format!("{} tags applied", applied))
        }
        _ => None,
    }
}

fn duration_ms_from_output(output: &JsonValue) -> Option<i64> {
    output.get("duration_ms").and_then(|v| v.as_i64())
}

pub fn build_step_states(
    pool: &DbPool,
    job_id: Uuid,
    job_status: &str,
    current_step: Option<&str>,
    current_step_started_at: Option<DateTime<Utc>>,
    failed_at_step: Option<&str>,
    job_error_message: Option<&str>,
) -> Result<Vec<StepState>, diesel::result::Error> {
    let mut conn = pool.get().expect("db pool");

    let outputs: Vec<(String, JsonValue, DateTime<Utc>)> = step_outputs::table
        .filter(step_outputs::scrape_job_id.eq(job_id))
        .select((step_outputs::step_name, step_outputs::output, step_outputs::created_at))
        .load(&mut conn)?;

    let mut by_name = std::collections::HashMap::new();
    for (name, output, created_at) in outputs {
        by_name.insert(name, (output, created_at));
    }

    let terminal = matches!(job_status, "completed" | "failed");
    let mut states = Vec::with_capacity(PIPELINE_STEPS.len());

    for step_name in PIPELINE_STEPS {
        let name = (*step_name).to_string();
        if let Some((output, created_at)) = by_name.get(&name) {
            let duration_ms = duration_ms_from_output(output);
            let finished_at = Some(*created_at);
            let started_at = duration_ms.map(|ms| *created_at - chrono::Duration::milliseconds(ms));
            states.push(StepState {
                name: name.clone(),
                status: "completed".to_string(),
                started_at,
                finished_at,
                duration_ms,
                summary: step_summary(&name, output),
                error: None,
                has_output: true,
            });
        } else if failed_at_step == Some(&name) {
            states.push(StepState {
                name: name.clone(),
                status: "failed".to_string(),
                started_at: current_step_started_at,
                finished_at: None,
                duration_ms: None,
                summary: None,
                error: job_error_message.map(|s| s.to_string()),
                has_output: false,
            });
        } else if !terminal && current_step == Some(&name) {
            states.push(StepState {
                name: name.clone(),
                status: "running".to_string(),
                started_at: current_step_started_at,
                finished_at: None,
                duration_ms: None,
                summary: None,
                error: None,
                has_output: false,
            });
        } else {
            states.push(StepState {
                name: name.clone(),
                status: "pending".to_string(),
                started_at: None,
                finished_at: None,
                duration_ms: None,
                summary: None,
                error: None,
                has_output: false,
            });
        }
    }

    Ok(states)
}

def _wait_terminal(scrape_api: ScrapeApi, job_id: str, timeout: float = 30.0):

## Task 5: `GET /api/scrape/{id}/steps/{step_name}/output`

**Files:**
- Create: `server/src/api/scrape/steps.rs`
- Modify: `server/src/api/scrape/mod.rs`
- Modify: `api/openapi.json` (regenerated)

**Why:** Raw per-step JSON is what makes failures debuggable. The endpoint is small, ownership-checked, and returns 404 on missing.

- [ ] **Step 1: Write the handler**

Create `server/src/api/scrape/steps.rs`:

```rust
use axum::extract::{Path, State};
use axum::http::StatusCode;
use axum::Json;
use diesel::prelude::*;
use serde_json::Value as JsonValue;
use uuid::Uuid;

use crate::auth::CurrentUser;
use crate::db::DbPool;
use crate::schema::{scrape_jobs, step_outputs};

/// Return the raw JSON output stored for a given step of a scrape job.
///
/// 404 if the job does not exist or does not belong to the caller, and also
/// 404 if no output has been written yet for the requested step name.
#[utoipa::path(
    get,
    path = "/api/scrape/{id}/steps/{step_name}/output",
    params(
        ("id" = Uuid, Path, description = "Scrape job ID"),
        ("step_name" = String, Path, description = "Pipeline step name"),
    ),
    responses(
        (status = 200, description = "Raw step output JSON", body = serde_json::Value),
        (status = 404, description = "Step output not found"),
    ),
    security(("bearer" = []))
)]
pub async fn get_step_output(
    State(pool): State<DbPool>,
    CurrentUser(user): CurrentUser,
    Path((job_id, step_name)): Path<(Uuid, String)>,
) -> Result<Json<JsonValue>, StatusCode> {
    let mut conn = pool.get().map_err(|_| StatusCode::INTERNAL_SERVER_ERROR)?;

    // Ownership check
    let owner: Option<Uuid> = scrape_jobs::table
        .filter(scrape_jobs::id.eq(job_id))
        .select(scrape_jobs::user_id)
        .first::<Uuid>(&mut conn)
        .optional()
        .map_err(|_| StatusCode::INTERNAL_SERVER_ERROR)?;

    match owner {
        Some(uid) if uid == user.id => {}
        _ => return Err(StatusCode::NOT_FOUND),
    }

    let output: Option<JsonValue> = step_outputs::table
        .filter(step_outputs::scrape_job_id.eq(job_id))
        .filter(step_outputs::step_name.eq(&step_name))
        .select(step_outputs::output)
        .order(step_outputs::created_at.desc())
        .first::<JsonValue>(&mut conn)
        .optional()
        .map_err(|_| StatusCode::INTERNAL_SERVER_ERROR)?;

    match output {
        Some(o) => Ok(Json(o)),
        None => Err(StatusCode::NOT_FOUND),
    }
}
```

## Task 7: `ScrapeStatusPage` component

**Files:**
- Create: `ramekin-ui/src/pages/ScrapeStatusPage.tsx`

**Why:** This is the whole point of the feature. A single page owns polling, step rendering, and terminal-state navigation.

- [ ] **Step 1: Look at neighbouring pages for conventions**

Run: `ls ramekin-ui/src/pages/` and open one of the simpler pages (e.g. `CapturePage.tsx`) to confirm the patterns for: using `useParams`, calling the generated client (`getScrapeApi().getScrape({ id })`), displaying errors, and navigating via `useNavigate`.

- [ ] **Step 2: Write the component**

Create `ramekin-ui/src/pages/ScrapeStatusPage.tsx`:

```tsx
import { useCallback, useEffect, useMemo, useRef, useState } from "react";
import { useNavigate, useParams } from "react-router-dom";

import { getScrapeApi } from "../api";
import type { ScrapeJobResponse, StepState } from "../../generated-client";

type ExpandedOutputs = Record<string, { loading: boolean; error?: string; output?: unknown }>;

const POLL_INTERVAL_MS = 1000;
const TERMINAL_STATUSES = new Set(["completed", "failed"]);

function formatDuration(ms?: number | null): string {
    if (ms == null) return "";
    if (ms < 1000) return `${ms}ms`;
    return `${(ms / 1000).toFixed(1)}s`;
}

function stepIcon(status: string): string {
    switch (status) {
        case "completed": return "✓";
        case "failed": return "✗";
        case "running": return "◐";
        case "skipped": return "−";
        default: return "○";
    }
}

export default function ScrapeStatusPage() {
    const { id } = useParams<{ id: string }>();
    const navigate = useNavigate();
    const [job, setJob] = useState<ScrapeJobResponse | null>(null);
    const [pollError, setPollError] = useState<string | null>(null);
    const [expanded, setExpanded] = useState<ExpandedOutputs>({});
    const [retrying, setRetrying] = useState(false);
    const abortRef = useRef(false);

    const poll = useCallback(async () => {
        if (!id) return;
        try {
            const resp = await getScrapeApi().getScrape({ id });
            if (!abortRef.current) setJob(resp);
        } catch (e) {
            if (!abortRef.current) setPollError(e instanceof Error ? e.message : String(e));
        }
    }, [id]);

    useEffect(() => {
        abortRef.current = false;
        void poll();
        const handle = window.setInterval(() => {
            if (job && TERMINAL_STATUSES.has(job.status)) return;
            void poll();
        }, POLL_INTERVAL_MS);
        return () => {
            abortRef.current = true;
            window.clearInterval(handle);
        };
    }, [poll, job]);

    const toggleExpand = useCallback(async (step: StepState) => {
        if (!id || !step.has_output) return;
        const name = step.name;
        const already = expanded[name];
        if (already) {
            setExpanded((prev) => {
                const next = { ...prev };
                delete next[name];
                return next;
            });
            return;
        }
        setExpanded((prev) => ({ ...prev, [name]: { loading: true } }));
        try {
            const resp = await fetch(`/api/scrape/${id}/steps/${encodeURIComponent(name)}/output`, {
                credentials: "include",
            });
            if (!resp.ok) throw new Error(`HTTP ${resp.status}`);
            const output = await resp.json();
            setExpanded((prev) => ({ ...prev, [name]: { loading: false, output } }));
        } catch (e) {
            setExpanded((prev) => ({
                ...prev,
                [name]: { loading: false, error: e instanceof Error ? e.message : String(e) },
            }));
        }
    }, [expanded, id]);

    const onRetry = useCallback(async () => {
        if (!id) return;
        setRetrying(true);
        try {
            await getScrapeApi().retryScrape({ id });
            await poll();
        } finally {
            setRetrying(false);
        }
    }, [id, poll]);

    const elapsed = useMemo(() => {
        if (!job) return "";
        const start = new Date(job.created_at).getTime();
        return formatDuration(Date.now() - start);
    }, [job]);

    if (!id) return <div>Invalid scrape ID</div>;
    if (pollError && !job) return <div className="error">Failed to load scrape: {pollError}</div>;
    if (!job) return <div>Loading…</div>;

    const isTerminal = TERMINAL_STATUSES.has(job.status);

    return (
        <div className="scrape-status-page">
            <header>
                <h1>Scrape</h1>
                {job.url && <div className="scrape-url">{job.url}</div>}
                <div className="status-pill" data-status={job.status}>{job.status}</div>
                <div className="elapsed">{elapsed}</div>
            </header>

            {job.status === "failed" && job.error && (
                <div className="error-banner">
                    <strong>Failed{job.failed_at_step ? ` at ${job.failed_at_step}` : ""}:</strong> {job.error}
                    {job.can_retry && (
                        <button onClick={onRetry} disabled={retrying}>
                            {retrying ? "Retrying…" : "Retry"}
                        </button>
                    )}
                </div>
            )}

            <ol className="step-list">
                {job.steps.map((step) => {
                    const expandedEntry = expanded[step.name];
                    const canExpand = step.has_output;
                    return (
                        <li key={step.name} className={`step step-${step.status}`}>
                            <button
                                className="step-row"
                                onClick={() => canExpand && toggleExpand(step)}
                                disabled={!canExpand}
                            >
                                <span className="icon">{stepIcon(step.status)}</span>
                                <span className="name">{step.name}</span>
                                {step.duration_ms != null && (
                                    <span className="duration">{formatDuration(step.duration_ms)}</span>
                                )}
                                {step.summary && <span className="summary">{step.summary}</span>}
                            </button>
                            {step.error && <div className="step-error">{step.error}</div>}
                            {expandedEntry && (
                                <div className="step-output">
                                    {expandedEntry.loading && "Loading output…"}
                                    {expandedEntry.error && <div className="error">{expandedEntry.error}</div>}
                                    {expandedEntry.output !== undefined && (
                                        <pre>{JSON.stringify(expandedEntry.output, null, 2)}</pre>
                                    )}
                                </div>
                            )}
                        </li>
                    );
                })}
            </ol>

            {isTerminal && job.recipe_id && (
                <div className="terminal-actions">
                    <button
                        className="view-recipe"
                        onClick={() => navigate(`/recipes/${job.recipe_id}`)}
                    >
                        View Recipe →
                    </button>
                </div>
            )}
        </div>
    );
}
```

If the project uses a specific API wrapper that already includes credentials / base URL for `fetch`, use that in the output-fetch call rather than a bare `fetch`. Look at how `CapturePage.tsx` issues its non-generated-client fetches for the right pattern.

`created_at` is added to the Rust response in Task 4 and will appear on the regenerated TS client after Task 6.
